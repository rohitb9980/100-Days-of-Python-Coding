**OOP stands for Object-Oriented Programming.** 



It is a programming paradigm that organizes software design around data (objects) rather than just functions and logic. 



By grouping related data and behaviors into individual "objects," developers can build modular, highly reusable, and scalable code.



The Core Concepts



Object-Oriented Programming relies on a few fundamental pillars that help structure the code cleanly:



Classes \& Objects: A class is a blueprint (like a cookie cutter), and an object is an instance of that class (the actual cookie created).Encapsulation: Binding the data and the methods that operate on that data into a single unit (like a capsule), restricting direct access to the inner workings.



Abstraction: Hiding complex implementation details and showing only the essential, relevant features of an object.



Inheritance: The ability for a new class to adopt the properties and behaviors of an existing class, which promotes code reuse.



Polymorphism: The ability for different objects to respond to the same method call in their own unique way.
